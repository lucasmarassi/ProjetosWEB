# ProjetosWEB

Repositório para organizar projetos web desenvolvidos ao longo do curso. Cada projeto fica em sua própria pasta.

## Projetos

### [sistema-academico](./sistema-academico/)

Sistema de gerenciamento acadêmico com CRUD de Alunos, Professores e Cursos, autenticação JWT e três implementações paralelas da API.

**Tecnologias:** PHP, Node.js (Express), Python (Flask), HTML/CSS, Bootstrap

**Estrutura:**

```
sistema-academico/
├── API_php/          # API REST completa em PHP com views HTML
├── API_javascript/   # API REST em Node.js com Express
├── flask/            # API em Python com Flask
└── Pagina_html/      # Páginas estáticas e portfólio
```

**Funcionalidades:**
- CRUD completo de Alunos, Professores e Cursos
- Autenticação com JWT
- Importação de dados via CSV
- Front-end com Bootstrap integrado à API PHP
